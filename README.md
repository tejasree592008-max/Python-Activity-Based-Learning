## Project Description

This repository contains 10 Python case studies completed as part of the Activity-Based Learning (ABL) assignment. The project focuses on solving different practical problems using Python programming concepts such as variables, conditional statements, loops, mathematical calculations, and user input.

Each case study includes the problem statement, objectives, assumptions, algorithm, flowchart, pseudocode, Python source code, test cases, sample output, and conclusion.

1. Attendance Recovery Computation
2. Progressive Electricity Billing

7. Food Waste Monitoring System
8. Multi-Stage Examination Eligibility System

10. Retail Billing with Multiple Discount Rules
